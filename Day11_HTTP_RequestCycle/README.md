## HTTP Request Lifecycle - Basic to Intermediate


# Employee Management API
This project demonstrates the HTTP Request Lifecycle using a FastAPI-based Employee Management API.

The project covers HTTP requests, responses, methods, headers, status codes, path parameters, query parameters, JSON data, validation, middleware, error handling, CORS, and API testing.

## Technologies Used

- Python
- FastAPI
- Uvicorn
- Pydantic
- Pytest
- HTTPX
- JSON
- Swagger/OpenAPI
