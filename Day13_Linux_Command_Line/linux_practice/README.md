
# Day 13 - Linux Command Line

## Overview
This project demonstrates basic to intermediate command-line
operations and shell scripting as part of the Syntova Technical
Readiness assignment.

## Topics Covered
- Directory navigation
- File and folder management
- Searching and text processing
- File permissions
- System and process information
- Shell scripting with variables, conditions, and loops

## Project Files
- `linux_command_notes.md` - Command explanations and notes
- `linux_practice/sample.txt` - Sample text used for practice
- `linux_practice/sample_backup.txt` - Copy of the sample file
- `linux_practice/search_results.txt` - Saved search results
- `linux_practice/practice.sh` - Shell scripting exercise

## How to Run
Open Git Bash in the `linux_practice` directory.

Run:
```bash
bash practice.sh
```

Check the script syntax:
```bash
bash -n practice.sh
```

## Environment
Windows with Git Bash.

## Learning Outcome
Practised file management, text searching, command pipelines,
basic permissions, and shell scripting.
